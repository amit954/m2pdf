What Is an MBOX File and How Do You Open One?

August 18, 2026
Photo by CHUTTERSNAP on Unsplash

You backed up your Gmail, waited for the download, and ended up with a single file ending in .mbox that nothing on your computer seems to open. If you double click it, your browser shrugs and your text editor shows a wall of gibberish. Nothing is broken. You just have a mailbox in a format most people never see directly.

This guide explains what an MBOX file actually is, where it comes from, and the simplest ways to open one and read the emails inside.

What Is an MBOX File?

An MBOX file is a single file that holds many emails, stored one after another in plain text. Instead of saving each message as its own file, the MBOX format packs an entire mailbox, sometimes thousands of emails, into one archive. Each message keeps its subject, sender, date, body, and attachments.

That is the key thing to understand: an MBOX file is not one email, it is a whole box of them. This is different from an EML file, which is a single message. If you want the difference in one line: EML is one letter, MBOX is the whole mailbag.

Where Do MBOX Files Come From?

You almost always end up with an MBOX file because you exported your email from one of these places:

  • Gmail, through Google Takeout. When you download a copy of your Gmail data, Google hands it to you as one or more .mbox files. This is the most common way people run into the format.
  • Mozilla Thunderbird. Thunderbird stores your mail in MBOX behind the scenes, and add-ons can export folders as .mbox files.
  • Apple Mail. Its export option saves mailboxes in the MBOX format.
  • Other clients and migrations. Many email tools import and export MBOX because it is a long-standing, widely supported format.

So if you have a .mbox file, it is usually a backup or an export of a real inbox, sitting there waiting for something that can read it.

Why Won't It Just Open?

The format is old and standard, but it was designed for email programs, not for double clicking. Your operating system has no default app tied to .mbox, so nothing happens, or the wrong app opens it as raw text. To read it properly you need something that understands the format and can pull each message out cleanly.

How to Open an MBOX File

You have a few options depending on what you actually want to do.

1. Open it in your browser, no software needed

The fastest way to just read your emails is a browser-based viewer. Our free MBOX to PDF converter opens the file, lists every email inside it, and lets you read any message with its attachments. Everything runs locally in your browser, so the file never leaves your device, which matters for a mailbox full of personal mail. From there you can save any email as a PDF for keeping or sharing.

2. Import it back into an email client

If you want the emails living inside a mail app again, Thunderbird is the usual choice. With the right add-on it can import an .mbox file and show the messages as a normal folder. This is heavier to set up, but it makes sense if you want to search and reply to the emails long term rather than just read or archive them.

3. Use a dedicated MBOX viewer app

There are desktop viewer apps built specifically for the format. They work, but they mean downloading and installing software for a file you may only need to open once, which is why a browser viewer is often the simpler answer.

Saving MBOX Emails as PDF

Often the real goal is not to keep the whole mailbox, but to pull out a few important emails and save them in a format you can file, print, or send to someone. PDF is ideal for that: it is universal, it preserves the layout, and it is easy to store.

With the browser viewer above, you open the .mbox file, click the email you need, and save it as a PDF with its attachments included. No installs, no uploads, and your data stays on your machine.

A Note on Very Large Files

Gmail Takeout exports can get big. If your .mbox file is enormous, the simplest fix is to re-run Google Takeout and choose a smaller export size, which splits your mail into several smaller .mbox files that are easier to open one at a time.

The Short Version

An MBOX file is a whole mailbox saved as one file, usually from Gmail Takeout, Thunderbird, or Apple Mail. It will not open on its own because nothing on your computer is set to read it. The quickest way to see what is inside is a browser-based MBOX viewer, which lets you read each email and save the ones you care about as PDF, all without uploading your mail anywhere.
